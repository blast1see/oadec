## M12 — objects against the source (encoder round trip)

`pi-head-dee.ec3` was encoded by DEE from the DAMF set oadec decoded from
the TrueHD stream, so the source objects are known. `oadec decode
--format damf` on the JOC stream, compared with the source over 40 s
(`tools/joc_roundtrip.py`, analytic-signal correlation):

- Total object energy: 99.7 % of the source. LFE: identical to the Dolby
  decode (127 dB), and both are 15.9 dB from the source at a lag of −10
  samples with gain 0.96, i.e. the encoder's LFE coding, not the decoder.
- Of the 15 JOC objects 4 are silent (the encoder used 11 for the 11 source
  objects). The three loudest objects (rms 0.03–0.04) match one source
  object each with |correlation| 0.986–0.989 and 15–17 dB; the weak ones
  (rms below 0.01) match with 0.78–0.88 and 2–5 dB; the quietest (rms below
  0.002) 0.4–0.6. JOC is parametric: the fidelity follows the object's
  level in the downmix.
- Downmix configuration 3 carries the surround pair with a 90° phase shift.
  Without correction the weak objects came back at −75° (|correlation| 0.82,
  real correlation 0.2). Rotating Ls and Rs by −j before the matrices puts
  every object within 4–14° of the source and raises the explained variance
  of every source object (e.g. 0.63 → 0.65, 0.50 → 0.54); rotating by +j or
  rotating the front channels makes it worse. oadec applies the −j rotation
  for configurations 3 and 4.
- The object timing: with the 256-sample decoder delay and the 577-sample
  filter bank delay removed, the LFE aligns with the Dolby decode at lag 0
  and the object sum with the source at lag −1.

The DAMF and ADM BWF written from the JOC stream pass `atmos_info

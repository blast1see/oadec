  5,075,800 frames × 21 channels (conformed 7.1.2 bed + 11 objects), 132
  events from 3,306 payloads.
- Dolby `atmos_info` (DEE 5.2.1) and `atmos_info --validate 1` (DEE 5.7.2):
  both exit 0 (`logs/pi-head.atmos_info_5*.log`).
- Events versus truehdd's `pi_p3.atmos.metadata` over the same span: same
  element ids, same event counts per element, identical values; the only
  differences are 21 event times that oadec places 32 samples later —
  the `block_offset_factor` term of the specification, which truehdd ignores.
- DEE `encode_to_atmos_ddp` (768 kbps) accepted the set: MediaInfo reports
  "E-AC-3 JOC / Dolby Digital Plus with Dolby Atmos", complexity index 16,
  15 dynamic objects + LFE bed (`dee/pi-head/pi-head-dee.ec3`, `ddp.log`).
- DEE `encode_to_dthd` (spatial clusters 16, input type `atmos_mezz`)
  produced a TrueHD Atmos stream (`pi-head-dee.mlp`) that `oadec verify`
  reports CLEAN; decoding it back to DAMF: the LFE bed channel is bit-exact
  (5,075,800 samples, lag 0), every object maps 1:1 to one encoded object
  (normalised correlation 1.000000) after a permutation, with a uniform gain
  of −0.00565 dB (ratio 0.999349, residual max |diff| 99 of 2^23) applied by
  the encoder's spatial coding; metadata events come back with the same
  values and counts, placed 1600 samples earlier by the encoder.
- In the encoder's E-AC-3 JOC output and in four streaming JOC tracks every
  OAMD update starts on a frame boundary (`oadec emdf`).

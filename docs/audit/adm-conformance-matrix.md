## Verdicts

- **Structural ADM verdict:** MOSTLY VALID. Every default (bed-conformed, 48 kHz) file passes the container, reference-graph, chna and Dolby Atmos Master ADM profile v1.0 checks and Dolby's own validators (with the origin tag); `--no-bed-conform` object IDs and non-48 kHz programmes leave the profile without a warning.

For scenes the corpus does not contain (non-zero gain, ISF, 3-D size, bed events, importance) the output would be STRUCTURALLY VALID BUT SEMANTICALLY INCOMPLETE, and nothing tells the user.
